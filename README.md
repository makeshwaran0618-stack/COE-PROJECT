Smart IV Monitoring System

 1. Project Overview

The Smart IV Monitoring System is a prototype designed to continuously monitor
IV fluid administration and provide timely alerts when attention is required.

The system aims to reduce the need for continuous manual checking and help
caregivers identify situations such as low IV fluid level or abnormal flow.

---

 2. Problem

In hospitals, IV fluid bottles need to be monitored regularly.

Nurses and caregivers may have to repeatedly check:

- Remaining IV fluid level
- Whether the IV fluid is flowing properly
- Whether the bottle is nearly empty
- Whether attention is required

Frequent manual monitoring can increase workload and may lead to delayed
attention during busy situations.

---

 3. Our Solution

I developed a prototype IV monitoring system that combines sensing,
embedded electronics and a monitoring interface.

The system continuously observes the IV setup and sends the collected
information to the monitoring system.

When a predefined abnormal condition is detected, the system can generate
an alert.

---

 4. Key Features

- Continuous IV monitoring
- Automatic detection of low fluid level
- Flow monitoring
- Alert generation
- Real-time monitoring interface
- Compact prototype
- Reduced need for repeated manual checking
- Designed with caregiver usability in mind
